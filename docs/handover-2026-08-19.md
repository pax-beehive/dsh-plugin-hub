## 新功能

### A1 GitHub topic 发现通道（source-only listings）

- 每 6 小时随同一个 cron 运行（`worker/index.ts` scheduled handler，`ctx.waitUntil` 追加，失败不影响 npm 调度）。
- 爬 GitHub search API 的 `topic:dsh-plugin` 和 `topic:deepseek-harness`，跳过 private/fork/archived，upsert 进 `github_source_listings`。
- **分页游标**：复用 `npm_discovery_cursors` 表，key 为 `github:topic:<topic>`，存的是**下一页页码**，`0` = 新一轮从第 1 页开始。每轮每 topic 最多 3 页（未认证 GitHub search 约 10 req/min）。403/429 暂停，下轮续爬。
- **source-only 展示**：`/plugins` 底部「GitHub 上的社区插件」区块，只显示未关联仓库（按 stars 排序，最多 12）。
- **自动升级**：作者发布 npm 包且 manifest repository 与 `full_name` 匹配时，`relinkAcceptedPlugins()`（每次发现跑完执行）写入 `linked_package_name`，source-only 卡片消失，正式 registry 卡片接管。
- 可选 secret `GITHUB_TOKEN`（只读 PAT）提高限额；不配也能跑。

### A2 GitHub 信任信号接入正式收录

- `pluginRecordSchema` 新增可选字段 `github: { stars, pushedAt? }`（strict object，向后兼容，Registry API 响应自动携带）。
- `D1RegistryStore.search()` / `findPackageWhere()` LEFT JOIN `github_source_listings`（`plugins.repository = full_name`）。
- 卡片标签行出现高亮 `★ n` 芯片（title 显示最近提交日期）；详情页侧栏新增 GitHub / 最近提交两行。

### A3 分类落地页 + SEO

- `/categories/[category]`：按作者声明分类精确聚合（`json_each` 等值匹配，"vision" 不会误中 "vision-pro"），复用卡片网格，顶部分类切换栏。
- `/plugins` 新增分类浏览栏（top 12 + 计数）。
- 新增 `app/sitemap.ts`（动态，含插件/Profile/分类 URL）和 `app/robots.ts`（屏蔽 `/dashboard`、`/api/`、`/integrations/`）。
- ⚠️ **vinext 坑**：metadata 路由模块会被 server entry 急切求值，顶层静态 import `cloudflare:workers`（经 `db/index.ts`）会让纯 Node 渲染测试炸掉。`sitemap.ts` 里 db 相关 import 放在函数体内动态加载——**以后新增 metadata 路由保持这个模式**。

### A4 公开 `/status` 页

- `D1NpmSyncStore.statusSummary()`（按状态聚合）+ `recentlySynced()`（最近 20 条）。
- 状态统计卡 + 最近同步表格（状态 pill 着色、last_error 列）。导航新增「Status」。已进 sitemap。
- 展示 GitHub source-only 计数（`D1GithubSourceStore.countPublic()`）。

### 前端视觉改造

## 部署步骤（Staging）

```bash

cat drizzle/0008_overconfident_husk.sql
```
